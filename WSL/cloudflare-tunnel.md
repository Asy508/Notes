# WSL + Cloudflare Tunnel Quick Test

## 1. Install/check WSL
* Using PowerShell (Administrator) Install
```
wsl --install
```
* Check
```
wsl -l -v
```
* Output: 
```
Ubuntu	Running	1/2
```

## 2. Enter Ubuntu
* From PowerShell
```
wsl
```
* Output:
```
rott@PC:~#
```
* Now, we're inside Linux
